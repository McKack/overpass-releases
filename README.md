# OverPass has moved

OverPass is open source now: **[github.com/McKack/overpass](https://github.com/McKack/overpass)**, with its
releases, issues and source. Landing page: [overpass.arctim.no](https://overpass.arctim.no).

Install:

```sh
curl -fsSL https://overpass.arctim.no/install | bash
```

This repository keeps the releases up to 0.3.2. OverPass 0.3.0 and older update from here to 0.3.2, which then
updates from the new repository. Nothing to do on your side: use Check for Updates… in OverPass.
